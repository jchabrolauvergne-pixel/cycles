Les verbes irréguliers 4e

De learn à write : base verbale, prétérit, participe passé

1. Les trois formes d'un verbe

Base verbalewrite
Prétéritwrote
Participe passéwritten
  • Le prétérit raconte une action passée et terminée, souvent datée (yesterday, last week, two days ago) :
    I wrote a letter yesterday.
  • Le participe passé s'emploie après have / has (present perfect) et au passif après be :
    I have written a letter. — This book was written by Roald Dahl.

Les verbes réguliers ajoutent simplement -ed (play → played → played). Les verbes irréguliers ne suivent pas cette règle : il faut les apprendre par cœur.

2. Astuces : les verbes qui se ressemblent

On retient mieux les verbes par familles :

i → a → u
sing sang sung · ring rang rung · swim swam swum
-t au prétérit
sleep slept · sweep swept · mean meant · lend lent · send sent · spend spent · smell smelt · learn learnt
-ought / -aught
think thought · teach taught
o → o + en
speak spoke spoken · steal stole stolen · wake woke woken
-ore → -orn
tear tore torn · wear wore worn
participe en -n / -en
take took taken · shake shook shaken · ride rode ridden · rise rose risen · write wrote written · see saw seen
-ew / -own
throw threw thrown · show showed shown
3 formes identiques
let · put · set · shut · spread · read
⚠️ Pièges
  • read s'écrit pareil, mais se prononce /ri:d/ au présent et /red/ au prétérit et au participe.
  • run → ran → run : le participe passé redevient comme la base.
  • lie → lay → lain (être allongé) : ne pas confondre avec lay (poser).
  • say = dire ; tell = raconter, dire à quelqu'un (tell me).
